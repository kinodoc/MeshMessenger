# Third-party transport references

## Briar / Bramble

MeshMessenger's Concept transport work is based on studying the public transport architecture of the Briar / Bramble project:

- https://github.com/briar/briar
- https://www.briarproject.org/

Briar / Bramble is licensed under GPLv3. The current `BriarBluetoothTransport` is an independent implementation of the transport contract and does not copy Briar source code. MeshMessenger packet framing, identity, end-to-end encryption and Relay protocol remain project-specific.
